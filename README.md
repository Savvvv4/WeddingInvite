# Vanshika & Swastik — Engagement Invitation

A responsive, five-page digital engagement invitation with a door-opening landing page.

## Event
- Wednesday, 2 December 2026
- Myst by The Zora, Lodhi Road, New Delhi

## What's inside
- Landing page with an arched cover; tapping **Open Invitation** parts the doors
- Names, invitation, save the date with countdown, venue, and a closing note
- Neutral ivory and charcoal palette with a hairline frame and small corner brackets
- **Add to Calendar** (Google Calendar, or an `.ics` file with reminders for Apple and Outlook) and **Get Directions** buttons

## Editing
All event details (date, title, venue) live at the top of `script.js`. Names and text are in `index.html`.

## Deploy on Vercel
This is a static site. Import the repository and use:
- Framework preset: Other
- Root directory: repository root
- Build command: leave blank
- Output directory: leave blank

No form or response collection is included.
